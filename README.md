# TAP to PICK

TAPtoTALK의 모바일 화면 구조와 폰트, 종이 질감 디자인을 바탕으로 만든 이미지 찾기 게임입니다.
완성 캐릭터 PNG와 정사각형 JPG 조각을 이용해 세 가지 모드를 플레이합니다.

## 게임 모드

1. **조각 찾기** — 완성 이미지를 보고 7×7 혼합 보드에서 해당 캐릭터의 모든 조각을 찾습니다. 완료 시간이 짧고 오답이 적을수록 고득점입니다.
2. **몽타주 찾기** — 처음은 3×3, 한 개를 찾으면 4×4, 두 개부터는 5×5 후보에서 정확히 같은 얼굴 하나를 찾습니다. 이후 5×5를 유지하며 전체 제한시간은 3분입니다. 일곱 캐릭터를 한 번씩 모두 제시한 뒤 새 랜덤 순서를 만들며, 결과에는 찾은 개수를 표시합니다.
3. **페어 메모리** — 4×4(8쌍·1분) → 5×5(12쌍·1분) → 6×6(18쌍·1분 30초) → 7×7(24쌍·2분)을 완료하면 한 판 성공입니다. 각 단계에서 3초 미리보기 후 타이머가 새로 시작하며, 시간 초과 시 한 판이 종료됩니다. 홀수 보드 중앙은 회색 별 빈칸입니다. 일곱 멤버의 원본 얼굴만 반복 사용하고 바리에이션은 제외합니다. 같은 얼굴 두 장이면 원래 쌍과 무관하게 정답입니다.

## 이미지 구성

- 캐릭터 폴더: `Bb`, `Ha`, `Hoo`, `Ja`, `Pino`, `Tapee`, `Tepee`
- PNG: 위쪽에 제시하는 완성 이미지
- JPG: 보드와 메모리 카드에 사용하는 이미지 조각. 파일 번호 순서대로 왼쪽 위부터 가로 방향으로 채웁니다.
- 9장은 `1–3 / 4–6 / 7–9`의 3×3, 12장은 `1–3 / 4–6 / 7–9 / 10–12`의 3×4입니다.
- `Tapee`는 완성 PNG가 없으므로 JPG 12장을 3×4로 조립해 목표 이미지를 표시합니다.
- 게임 2는 해피·뽀글스·태피·티피·후피·재피·피노팬의 얼굴 정답과 제공된 바리에이션을 사용합니다. 최적화 파일은 `optimized/montage/` 아래 캐릭터별 폴더에 둡니다.
