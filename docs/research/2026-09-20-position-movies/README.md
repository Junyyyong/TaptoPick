# POSITION 결과별 영상

- 시간 초과: notbad.
- 일반 완주(첫 완주 포함): 마지막으로 정답 페어를 맞춘 얼굴의 캐릭터 영상. 티피도 포함한다. 태피는 Unbelievable.
- 이전 완주 기록보다 빠른 최고기록 경신: OH MY GOD 영상과 별도 MP3.

최초 완주와 동률은 특별 영상 대상이 아니다. 이전 실패 기록만 있는 상태에서 첫 완주해도 일반 영상이다. 성공 여부·최고기록 판정과 캐릭터 매핑을 테스트하며, 기존 영상 기준 오디오 동기화 방식을 유지한다. 이전 랜덤 선택은 POSITION에서 더 이상 사용하지 않는다.
