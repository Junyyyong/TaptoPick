# 완료 영상·음원 시작 동기화

## 원인과 변경

기존 Cheer는 별도 video와 audio의 play를 바로 연속 호출했다. 영상의 실제 재생 시작을 기다리지 않아 다운로드·디코딩이 늦으면 소리가 먼저 나올 수 있었다.

MediaSync를 추가해 영상 playing 이벤트 이후에만 소리를 시작한다. 소리 메타데이터가 늦으면 준비된 후 영상 시간에 맞춘다. waiting/pause/seeking/ended/error 때 소리를 멈추고, 재개 및 timeupdate에서 120ms 넘는 시간 차이를 보정한다. 음소거 상태와 종료 시점도 반영한다. 화면 복귀 시 오디오를 따로 시작하던 코드도 같은 동기화 경로를 사용한다.

늦게 완료되는 재생 요청·초기 무음 해제 요청이 새 재생을 중단하지 않도록 버전 검사를 추가했다. 게임 규칙·원본 영상·배경음악은 변경하지 않았다. 영상 자체의 다운로드 지연을 없애는 변경은 아니며, 영상 준비 전 소리가 앞서 나오는 문제를 줄이는 변경이다. 영상 길이 제한은 기존 15초 그대로다.

## 검증

- MediaSync 단위 테스트 11개 추가: 시작 대기, 버퍼링, 늦은 오디오 준비, 오차 보정, 일시정지/종료/오류, 음소거와 취소.
- 전체 269개 테스트와 빌드 통과.
- check.cjs는 실제 티피 WebM/MP3를 Chromium에서 재생해 시작 순서·일시정지·재개·시간 차이를 측정한다. 자동재생 허용 및 음소거로 실행한 로컬 검증이며 결과는 checks.json에 저장한다.
- 시간 동기화 변경이므로 정지 스크린샷 대신 이벤트 순서와 시간차를 기록한다. 실제 iPhone 및 느린 네트워크에서의 체감은 추가 확인이 필요하다.
